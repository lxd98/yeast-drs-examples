Read selection, density calculations and interpretation
This view reuses the 6,984 reads and per-read geometry from the cached alignment analysis: same strand, MAPQ >10, nonsecondary alignments, exon overlap and the existing upstream-extension screen. The cohort includes 6,964 primary and 20 supplementary alignments. Each read has its own row; no read sampling is used.
Choose whether coverage and density tracks show all retained reads or the filtered set. Reference annotation and database regions remain fixed. The summary controls above the panels show the selected cohort and read count. With all reads, the original R density curves are reused. For subsets, Gaussian KDE is recalculated with adjust = 1 and R’s nrd0 bandwidth rule; calculation uses the direct Gaussian kernel rather than R’s FFT approximation. Density is per nucleotide, not read number. An empty or single-position set has no estimable KDE.
Coordinates are 1-based inclusive, increasing left to right. TIM8 is on the plus strand, so transcription proceeds left to right. Read 5′/3′ coordinates are strand-aware. The annotated coding start and stop-codon end are reference landmarks, not UTR boundaries.
A positive pt estimate does not establish an intact 5′ end. Zero, −1 and missing tags are shown separately without assuming they prove absence of a tail. Internal starts and internal ends remain observations, not confirmed initiation/termination mechanisms.
Panel choices are saved in this browser. Exports contain the currently filtered read IDs and metadata; source files and benchmark calls are unchanged. All content works locally without a server. Viewer methods.
